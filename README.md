# Fliki for Claude

Make images, video clips, music, speech, complete videos, audio, designs and your own templates
with [Fliki](https://fliki.ai) from Claude.

## Install

**Claude Desktop:** open Settings → Plugins, choose Add → Add marketplace, enter
`nine-thirty-five/fliki-claude-marketplace`, then install Fliki.

**Claude Code:**

```bash
claude plugin marketplace add nine-thirty-five/fliki-claude-marketplace && claude plugin install fliki@fliki
```

The first time Claude uses Fliki, sign in to your Fliki account when asked. In Claude Code, run
`/mcp` and choose Authenticate. Fliki for Claude is included with the Premium and Enterprise plans.

This repository is published automatically from Fliki's source; changes made here are overwritten.
For help, write to support@fliki.ai.
